# GramSathi AI — Prototype

A responsive, front-end prototype for the VBYLD 2027 “Hack for Social Cause” concept.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No package installation or server is required.

## Features
- Responsive home page and scheme discovery directory
- Search and category/audience filters
- Scheme detail modal
- Rule-based eligibility discovery demo
- Guided FAQ assistant (not a live AI model)
- Small Hindi/English toggle for selected hero text
- Accessible labels, status messages, and mobile layout

## Important limitations
- This is a demonstration prototype, not an official government service.
- Scheme listings are illustrative categories, not a verified or exhaustive government database.
- Eligibility suggestions are not official determinations.
- The assistant uses simple keyword rules and is not connected to an AI API.
- No personal data is stored or sent to a server.
- Before public launch, verify every scheme against official government sources, add official links, test with users, and review privacy/security.

## Suggested next steps

## Tech stack
HTML5, CSS3, and vanilla JavaScript. The prototype has no external dependencies.
